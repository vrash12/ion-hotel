## Privacy and demo behavior

The inquiry form handles input only in the current browser page. It makes no network submission, uses no cookies or browser storage, and displays an explicit demo result. Real contact actions open the hotel's phone/Facebook destinations only when selected. No analytics, third-party fonts, embedded maps or booking integrations are included.
